# Gauntlet Roles and Expertise Packs — Implementation Plan

**Goal:** Implement the frozen gauntlet design — deterministic stage packs (evidence boundaries that decide acceptance) plus advisory expertise packs, fingerprint-bound evidence, four-valued verification results, bootstrap exemptions, and the §12 self-test battery — entirely as repository convention.

**Architecture:** `scripts/candidate-fingerprint` becomes the single implementation of both digests and of task scheduling/classification, shared by `verify-candidate` (enforcement) and `agent-context` (display) so they cannot disagree. `verify-candidate` grows a Python heredoc engine that emits four-valued `{name, gate, required, result, exitCode, code}` rows for policy/evidence/task checks; a report writer applies exemptions and computes overall status. `scripts/selftest` builds fixture repositories in temp dirs and asserts every §12 matrix row against real reports.

**Tech Stack:** Bash (orchestration, existing check registry), Python 3 stdlib (fingerprints, engine, report writer, selftest), PyYAML (role-pack front matter, conditional), Git (file enumeration only — offline).

**Design under implementation:** `docs/superpowers/specs/2026-09-25-gauntlet-roles-design.md` (frozen; sections referenced as §N throughout).

## Design interpretation notes (frozen for this plan)

These resolve points the design left open. Each is a consequence of fail-closed or deadlock-avoidance reasoning recorded during planning; they are normative for this implementation.

1. **Bootstrap Go skips (deadlock avoidance).** Design §8.3 says Go checks are `required iff class == product`. FJ-001 (allowedFiles includes `go.mod`) is `product`, but `go.mod` does not exist yet — strict requiredness would block FJ-001 before it can create it. Therefore, in addition to `metadata` → `not_applicable (stage.not_required)` (§9.3): (a) `product` + no `go.mod` → Go checks `skipped`, `required: false`, reason `no go.mod yet`; (b) `go.mod` present but zero repository Go packages → `skipped`, `required: false`, reason `no repository Go packages yet`; (c) no `cmd/fake-jev` → build `skipped`, `required: false`. Once the artifacts exist, product items get `required: true` and real failures block. These skips never mask an existing failure — there is nothing to run.
2. **Exemptions apply only to `skipped` results.** §9.2 waives *unavailable* tooling; a `fail` is never exempted. Matching is `gate` + `blocks`-contains-code + item class in `scope`, applied in the report writer, only when a task id (hence a class) exists.
3. **Role-pack violations use code `agent.role_pack_invalid`.** The design requires failing closed on §4 violations but does not name a code; report codes are a spec-independent house rule (see `check_code` comment in `verify-candidate`), so this is an implementation choice, not public behavior.
4. **`gate.invalid_result` is materialized as `result: fail`.** A required check reported `not_applicable` is rewritten by the report writer to `result: fail`, `code: gate.invalid_result`, reason `required check reported not_applicable`. Exit is non-zero either way; the row stays visible.
5. **Invalid policy blocks stage rows.** If `policy.classification` or `policy.required_stages` fails, the engine emits no stage/evidence rows (the due set is untrustworthy) — verification is already blocked.
6. **Missing/invalid predecessor suppresses the chain row.** A chain check is emitted only when the predecessor artifact exists with a valid header; the predecessor's own `artifact`/`evidence_invalid` row already blocks.
7. **`blocked`/`planned`/`ready` have no due stages.** §8.1 gives `blocked` "evidence preserved, no new requirements" → nothing newly due; nothing blocks that is not already blocked by status.
8. **Scheduling lives in `candidate-fingerprint task`.** The due/pending split (§8.1) is derived from the same input as the task fingerprint, so `verify-candidate` and `agent-context` cannot render it differently — the same argument §6.2 makes for sharing the fingerprint implementation.
9. **Mode values are strings** (`"100644"`, `"100755"`, `"120000"`) in the candidate canonical JSON; the design shows them unquoted. Strings keep octal-looking values unambiguous.
10. **Test seam `GAUNTLET_SELFTEST_NA=<check-name>`.** Marks the named row `not_applicable` so §12 row 4 (required+NA) is reachable. It can only *create* a failure (`gate.invalid_result`), never mask one, so it is safe to leave in production code.
11. **PyYAML shadowing for tests:** a `PYTHONPATH` shim directory containing `yaml.py` that raises `ImportError` makes PyYAML "absent" without touching the environment.
12. **Fixed §10 defect (already committed at `844931f`):** non-exempt blocked skips collapse to `fail`, not `pass`.
13. **FJ-043 lifecycle:** created in Task 1 as the authorizing umbrella item; ends at `status: review` with retroactively synthesized stage artifacts (like FJ-PRD-001). `ready → review` without intermediate statuses is recorded in its `notes` — there is no workflow engine to enforce transitions (design §14), and the stages were executed as this plan's documentation/tooling work.

- [ ] **Step 2: Write `scripts/candidate-fingerprint`**

```python
#!/usr/bin/env python3
"""candidate-fingerprint — deterministic workspace and task digests.

usage:
  candidate-fingerprint candidate [ROOT]
  candidate-fingerprint task <path/to/state.json>

candidate  prints the sha256 candidate fingerprint of the workspace content
           (design §6.1) on stdout, exit 0.
task       prints one JSON object on stdout:
           {"taskFingerprint": "...", "class": "product|metadata|unknown",
            "requiredStages": [...] or null, "derivedRequiredStages": [...] or null,
            "source": "derived"|"explicit"|null, "status": ..., "stage": ...,
            "due": [...], "pending": [...]}

exit codes: 0 ok; 1 usage/argument error; 2 state.json unreadable or malformed;
            3 cannot classify (unknown scope and no explicit requiredStages);
            4 git metadata unavailable or listing failed (candidate mode only).

Offline, deterministic, no timestamps. Design: docs/superpowers/specs/
2026-09-25-gauntlet-roles-design.md §6, §8.1, §8.2.
"""

import hashlib
import json
import os
import stat
import subprocess
import sys

CANONICAL_STAGES = ["specifier", "coder", "cleaner", "hardener", "qa"]
EXCLUDED_PREFIXES = (".agent/work/", ".agent/reports/", ".agent/logs/", ".scratch/")
PRODUCT_PREFIXES = ("cmd/", "internal/", "test/", "testdata/", "spec/contracts/")
PRODUCT_FILES = ("go.mod", "go.sum")
METADATA_PREFIXES = ("docs/", ".agent/", "scripts/", ".github/", "spec/", "examples/")
METADATA_FILES = ("Dockerfile", "README.md", "AGENTS.md", "CONTEXT.md", ".gitignore")
# Frozen include-set (§6.2). Everything else in state.json is non-semantic.
SEMANTIC_FIELDS = ("id", "objective", "nonGoals", "acceptance", "specReferences",
                   "allowedFiles", "verificationCommands")


def die(message, code):
    print("candidate-fingerprint: %s" % message, file=sys.stderr)
    sys.exit(code)


def default_root():
    return os.path.dirname(os.path.dirname(os.path.realpath(__file__)))


def git_ok(root):
    proc = subprocess.run(["git", "-C", root, "rev-parse", "--git-dir"],
                          capture_output=True)
    return proc.returncode == 0


def git_paths(root, *args):
    proc = subprocess.run(["git", "-C", root, "ls-files", "-z", *args],
                          capture_output=True)
    if proc.returncode != 0:
        die("git ls-files failed: %s"
            % proc.stderr.decode("utf-8", "replace").strip(), 4)
    return [p for p in proc.stdout.decode("utf-8", "surrogateescape").split("\0") if p]


def excluded(path):
    return path.startswith(EXCLUDED_PREFIXES)


def file_entry(root, rel):
    full = os.path.join(root, rel)
    st = os.lstat(full)
    if stat.S_ISLNK(st.st_mode):
        mode = "120000"
        content = os.readlink(os.fsencode(full))
    else:
        mode = "100755" if (st.st_mode & 0o111) else "100644"
        with open(full, "rb") as handle:
            content = handle.read()
    return {"path": rel, "mode": mode,
            "contentSha256": hashlib.sha256(content).hexdigest()}


def candidate_fingerprint(root):
    if not git_ok(root):
        die("git metadata unavailable for %s" % root, 4)
    paths = set()
    for rel in git_paths(root) + git_paths(root, "--others", "--exclude-standard"):
        if excluded(rel):
            continue
        paths.add(rel)
    entries = []
    for rel in sorted(paths):
        # Tracked-but-deleted is not workspace content: identical to never having
        # the file, so a staged deletion and a committed deletion agree.
        if not os.path.lexists(os.path.join(root, rel)):
            continue
        entries.append(file_entry(root, rel))
    canonical = json.dumps(entries, sort_keys=True, separators=(",", ":"),
                           ensure_ascii=False)
    return hashlib.sha256(canonical.encode("utf-8", "surrogateescape")).hexdigest()


def classify_path(path):
    for prefix in PRODUCT_PREFIXES:
        if path.startswith(prefix):
            return "product"
    if path in PRODUCT_FILES:
        return "product"
    for prefix in METADATA_PREFIXES:
        if path.startswith(prefix):
            return "metadata"
    if path in METADATA_FILES:
        return "metadata"
    return None


def classify(paths):
    """Strongest policy wins: product > metadata; any unknown path fails closed."""
    if not paths:
        return None, ["(allowedFiles is empty)"]
    unknown = [p for p in paths if classify_path(p) is None]
    if unknown:
        return None, unknown
    classes = set(classify_path(p) for p in paths)
    return ("product" if "product" in classes else "metadata"), []


def derive_required_stages(cls):
    if cls == "product":
        return list(CANONICAL_STAGES)
    if cls == "metadata":
        return ["specifier", "coder", "cleaner", "qa"]
    return None


def scheduling(status, stage, required):
    """§8.1 due/pending split. pending stages emit no check (§8.3)."""
    if not required:
        return [], []
    if status in ("planned", "ready", "blocked"):
        due = []
    elif status == "implementing":
        due = list(required[:required.index(stage)]) if stage in required else list(required)
    elif status == "verifying":
        due = list(required[:required.index(stage) + 1]) if stage in required else list(required)
    elif status in ("review", "complete"):
        due = list(required)
    else:
        due = []
    pending = [s for s in required if s not in due]
    return due, pending


def task_info(path):
    try:
        with open(path, encoding="utf-8") as handle:
            state = json.load(handle)
    except (OSError, ValueError) as exc:
        die("cannot read %s: %s" % (path, exc), 2)
    if not isinstance(state, dict):
        die("%s must contain a JSON object" % path, 2)
    paths = state.get("allowedFiles")
    if not isinstance(paths, list) or any(not isinstance(p, str) for p in paths):
        die("allowedFiles must be a list of strings", 2)
    cls, unknown = classify(paths)
    explicit = state.get("requiredStages")
    if explicit is not None and not isinstance(explicit, list):
        die("requiredStages must be a list or absent", 2)
    derived = derive_required_stages(cls)
    if explicit is not None:
        effective, source = explicit, "explicit"
    elif derived is not None:
        effective, source = derived, "derived"
    else:
        die("cannot classify allowedFiles: %s" % ", ".join(unknown[:5]), 3)

    # §6.2 canonical task object: sorted keys, no insignificant whitespace,
    # arrays in stored order, absent/null fields omitted entirely.
    obj = {}
    for key in SEMANTIC_FIELDS:
        if key in state and state[key] is not None:
            obj[key] = state[key]
    if effective is not None:
        obj["requiredStages"] = effective
    if state.get("requiredStagesJustification") is not None:
        obj["requiredStagesJustification"] = state["requiredStagesJustification"]
    canonical = json.dumps(obj, sort_keys=True, separators=(",", ":"),
                           ensure_ascii=False)
    fingerprint = hashlib.sha256(canonical.encode("utf-8")).hexdigest()

    status, stage = state.get("status"), state.get("stage")
    rs = effective if isinstance(effective, list) else []
    due, pending = scheduling(status, stage, rs)
    print(json.dumps({
        "taskFingerprint": fingerprint,
        "class": cls or "unknown",
        "requiredStages": effective,
        "derivedRequiredStages": derived,
        "source": source,
        "status": status,
        "stage": stage,
        "due": due,
        "pending": pending,
    }, sort_keys=True, separators=(",", ":"), ensure_ascii=False))


def main(argv):
    if argv and argv[0] == "candidate":
        if len(argv) > 2:
            die("usage: candidate-fingerprint candidate [ROOT]", 1)
        root = argv[1] if len(argv) == 2 else default_root()
        print(candidate_fingerprint(root))
        return
    if argv and argv[0] == "task":
        if len(argv) != 2:
            die("usage: candidate-fingerprint task <state.json>", 1)
        task_info(argv[1])
        return
    die("usage: candidate-fingerprint candidate [ROOT] | task <state.json>", 1)


if __name__ == "__main__":
    main(sys.argv[1:])
```

#!/usr/bin/env python3
"""selftest — scenario suite for the gauntlet tooling (design §12).

usage: scripts/selftest [substring-filter ...]

Builds fixture repositories in temp directories (never modifies this
repository), runs the real scripts against them, and asserts results.
Each filter selects scenarios whose name contains it (OR semantics).
Offline: no network, no sleeps. Exit 0 iff every selected scenario passes.
"""

import hashlib
import json
import os
import pathlib
import shutil
import subprocess
import sys
import tempfile
import traceback

REAL = pathlib.Path(__file__).resolve().parent.parent
SCENARIOS = []
_PRISTINE = None
_PRISTINE_DIR = None

COPY_FILES = ["scripts/verify-candidate", "scripts/agent-context",
              "scripts/candidate-fingerprint", "README.md", "AGENTS.md", ".gitignore"]
COPY_DIRS = ["docs", "spec"]


def scenario(name):
    def decorate(fn):
        SCENARIOS.append((name, fn))
        return fn
    return decorate


def sh(cmd, cwd, env=None, check=True):
    merged = dict(os.environ)
    merged.update(env or {})
    proc = subprocess.run(cmd, shell=True, cwd=str(cwd), env=merged,
                          capture_output=True, text=True)
    if check and proc.returncode != 0:
        raise AssertionError("command failed (%d): %s\n%s\n%s"
                             % (proc.returncode, cmd, proc.stdout, proc.stderr))
    return proc


def git_commit(root):
    sh("git -c user.email=selftest@example -c user.name=selftest "
       "commit -qm fixture", root)


def git_init(root):
    sh("git init -q", root)
    sh("git add -A", root)
    git_commit(root)


def build_pristine(directory):
    """One-time copy of the real repository's tooling + docs into a temp git repo."""
    root = pathlib.Path(directory) / "pristine"
    root.mkdir(parents=True)
    for rel in COPY_FILES:
        shutil.copy2(REAL / rel, root / rel)
    for rel in COPY_DIRS:
        shutil.copytree(REAL / rel, root / rel, symlinks=True)
    (root / ".agent").mkdir()
    shutil.copy2(REAL / ".agent" / "README.md", root / ".agent" / "README.md")
    if (REAL / ".agent" / "schema").is_dir():
        shutil.copytree(REAL / ".agent" / "schema", root / ".agent" / "schema")
    if (REAL / ".agent" / "gate-policy.json").is_file():
        shutil.copy2(REAL / ".agent" / "gate-policy.json",
                     root / ".agent" / "gate-policy.json")
    git_init(root)
    return root


def pristine():
    global _PRISTINE, _PRISTINE_DIR
    if _PRISTINE is None:
        _PRISTINE_DIR = tempfile.TemporaryDirectory(prefix="gauntlet-selftest-")
        _PRISTINE = build_pristine(_PRISTINE_DIR.name)
    return _PRISTINE


def fixture(name, items=None, mutate=None):
    """Fresh copy of the pristine fixture plus optional work items/mutations."""
    root = pathlib.Path(tempfile.mkdtemp(prefix="st-%s-" % name))
    dest = root / "repo"
    shutil.copytree(pristine(), dest, symlinks=True)
    for task_id, state in (items or {}).items():
        work = dest / ".agent" / "work" / task_id
        work.mkdir(parents=True)

def rows(report, name):
    found = [c for c in report["checks"] if c["name"] == name]
    if not found:
        raise AssertionError("no check named %r; have: %s"
                             % (name, sorted({c["name"] for c in report["checks"]})))
    return found[0]


def expect(report, name, *, code=None, result=None, required=None, gate=None):
    row = rows(report, name)
    for key, want in (("code", code), ("result", result),
                      ("required", required), ("gate", gate)):
        if want is not None and row.get(key) != want:
            raise AssertionError("%s: %s=%r, want %r (row: %s)"
                                 % (name, key, row.get(key), want, row))
    return row


def assert_exit(proc, want_zero, context=""):
    got_zero = proc.returncode == 0
    if got_zero != want_zero:
        raise AssertionError("%sexit %d, want zero=%s\n%s"
                             % (context, proc.returncode, want_zero, proc.stdout))

def candidate_untracked_and_symlink_modes():
    with tempfile.TemporaryDirectory() as td:
        root = pathlib.Path(td) / "r"

        (root / ".gitignore").write_text("ignored/\n")

        (root / "plain.txt").write_text("plain\n")
        (root / "tool.sh").write_text("#!/bin/sh\n")
        (root / "tool.sh").chmod(0o755)
        os.symlink("plain.txt", (root / "link"))
        (root / "ignored").mkdir()
        (root / "ignored" / "x.bin").write_text("nope\n")
        fp = candidate_fp(root, root)

        # Independent recomputation of the canonical form for this tiny tree
        # (§6.1 rules: repo-relative / paths, string modes, gitignored excluded,
        #  symlink content = link target bytes).
        entries = []
        for rel, mode, content in [
            (".gitignore", "100644", b"ignored/\n"),
            ("base.txt", "100644", b"b\n"),
            ("link", "120000", b"plain.txt"),
            ("plain.txt", "100644", b"plain\n"),
            ("tool.sh", "100755", b"#!/bin/sh\n"),
        ]:
            entries.append({"path": rel, "mode": mode,
                            "contentSha256": hashlib.sha256(content).hexdigest()})
        entries.sort(key=lambda e: e["path"])
        canonical = json.dumps(entries, sort_keys=True, separators=(",", ":"))
        expected = hashlib.sha256(canonical.encode()).hexdigest()
        assert fp == expected, "digest %s != independently computed %s" % (fp, expected)

#!/usr/bin/env bash
# verify-candidate [task-id]
#
# Deterministic verification entry point for this repository. Offline: no network,
# no model/provider calls, no services. Prints each check it runs.
#
# Every check is a row {name, gate, required, result, exitCode, code, exempted}
# with result in {pass, fail, skipped, not_applicable} (design §9.1). The run is
# acceptable iff no required row is `fail` or a non-exempt `skipped`, and no
# required row is invalidly `not_applicable` (rewritten to gate.invalid_result).
#
# With a task id, structured evidence is written to
# .agent/reports/<task-id>/report-<utc-timestamp>.json, bound to the candidate
# fingerprint and — once the task engine lands — the task fingerprint.
#
# PRODUCT VERIFICATION EXPANDS HERE: as implementation phases land, add the product
# checks centrally (e.g. `go test ./...`, `go vet ./...`, `go build ./cmd/fake-jev`
# once go.mod exists, then contract/integration checks defined by the specification).
# Do not fork per-task verification scripts. Checks that cannot apply yet are
# reported as "skipped", never as a silent pass.
#
# Exit codes: 0 = acceptable; 1 = a required check is fail/skipped-without-exemption,
# or a usage/state error.

usage() {
  echo "usage: $0 [task-id]" >&2
  exit 1

[ "$#" -le 1 ] || usage
TASK_ID="${1:-}"

REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"

CHECK_CODES=()

# record_row <name> <display> <gate> <required 0/1> <result> <exit> <code> <reason>
# One row per check; the report writer (python) turns these into report v2 and
# computes the overall status. display/reason are flattened to one line so the
# TSV hand-off stays unambiguous.
record_row() {
  local name="$1" display="$2" gate="$3" required="$4" result="$5"
  local exit_code="$6" code="$7" reason="$8"
  display="${display//$'\t'/ }"
  display="${display//$'\n'/ }"
  reason="${reason//$'\t'/ }"
  reason="${reason//$'\n'/ }"
  CHECK_NAMES+=("$name")
  CHECK_CMDS+=("$display")
  CHECK_GATES+=("$gate")
  CHECK_REQUIRED+=("$required")
  CHECK_RESULTS+=("$result")
  CHECK_EXITS+=("$exit_code")
  CHECK_CODES+=("$code")
  CHECK_EXEMPTED+=("0")
  CHECK_REASONS+=("$reason")
}

# Stable machine code per check. Reports carry it so a failure is data, not prose:
# agents fingerprint repeated failures from code + check name instead of scraping
# stderr (spec-independent house rule, see docs/development/agent-workflow.md).
check_code() {
  case "$1" in
    check_required_files)      echo "repo.required_files_missing" ;;
    check_scripts_executable)  echo "repo.scripts_not_executable" ;;
    check_shell_syntax)        echo "shell.syntax_error" ;;
    check_toolchain_python3)   echo "toolchain.python3_missing" ;;
    check_spec_present)        echo "spec.missing" ;;
    check_json_files)          echo "agent.json_malformed" ;;
    check_work_item_schema)    echo "agent.work_item_schema" ;;
    check_role_packs)          echo "agent.role_pack_invalid" ;;
    check_go_test)             echo "go.test_failed" ;;
    check_go_vet)              echo "go.vet_failed" ;;
    check_go_build)            echo "go.build_failed" ;;
    *)                         echo "verify.check_failed" ;;

}

# run_check <display> <function> [required=1] [gate=G-C] — runs the check
# function in a subshell so that a failing `exit` inside a check cannot abort
# the whole verification run.
run_check() {
  local display="$1" fn="$2" required="${3:-1}" gate="${4:-G-C}" rc code result
  code="$(check_code "$fn")"
  printf '==> %s\n' "$display"
  set +e
  ( "$fn" )
  rc=$?
  set -e
  if [ "$rc" -eq 0 ]; then
    result="pass"
    printf '    PASS\n\n'
  else
    result="fail"
    printf '    FAIL (exit %s, code %s)\n\n' "$rc" "$code"
  fi
  record_row "$fn" "$display" "$gate" "$required" "$result" "$rc" "$code" ""
}

# skip_check <display> <function> <reason> [code] [required=1] [gate=G-C]
skip_check() {

  fi
  printf '==> %s\n    SKIPPED: %s\n\n' "$display" "$reason"
  record_row "$fn" "$display" "$gate" "$required" "skipped" "-1" "$code" "$reason"
}

def exemption_rows():
    """§9.2: every exemption needs an existing, non-complete trackedBy item."""
    path = ".agent/gate-policy.json"
    if not os.path.isfile(path):
        return  # absence already fails repo.required_files_missing
    unknown, stale = [], []
    exemptions = None
    try:
        data = load_json(path)
    except ValueError:
        unknown.append("gate-policy.json is not valid JSON")
        data = None
    if isinstance(data, dict):
        exemptions = data.get("exemptions")
    if not isinstance(exemptions, list):
        unknown.append("exemptions must be a list")
        exemptions = []
    for index, exemption in enumerate(exemptions):
        label = f"exemptions[{index}]"
        if not isinstance(exemption, dict):
            unknown.append(f"{label} must be an object")
            continue
        shape_ok = True
        for key in ("gate", "blocks", "scope", "code", "reason", "trackedBy"):
            if key not in exemption:
                unknown.append(f"{label} missing {key}")
                shape_ok = False
        if shape_ok:
            if exemption["gate"] not in GATE_IDS:
                unknown.append(f"{label}.gate {exemption['gate']!r} is not a known gate")
                shape_ok = False
            for key in ("blocks", "scope"):
                value = exemption[key]
                if (not isinstance(value, list) or not value
                        or not all(isinstance(item, str) for item in value)):
                    unknown.append(f"{label}.{key} must be a non-empty list of strings")
                    shape_ok = False
            if not isinstance(exemption.get("code"), str) or not exemption["code"]:
                unknown.append(f"{label}.code must be a non-empty string")
                shape_ok = False
            if not isinstance(exemption.get("reason"), str) or not exemption["reason"].strip():
                unknown.append(f"{label}.reason must be a non-empty string")
                shape_ok = False
        if not shape_ok:
            continue
        tracked = exemption["trackedBy"]
        if not isinstance(tracked, str) or not tracked.strip():
            unknown.append(f"{label}.trackedBy must be a non-empty string")
            continue
        state_path = f".agent/work/{tracked}/state.json"
        if not os.path.isfile(state_path):
            unknown.append(f"{label}.trackedBy {tracked}: no such work item")
            continue
        try:
            state = load_json(state_path)
        except ValueError:
            unknown.append(f"{label}.trackedBy {tracked}: unreadable state.json")
            continue
        if state.get("status") == "complete":
            stale.append(f"{label}.trackedBy {tracked} reached complete "
                         "— remove the exemption or ship the tooling")
    if unknown:
        emit("policy.exemptions.unknown", "G-C", True, "fail", 1,
             "policy.exemption_unknown",
             "trackedBy references resolve to existing work items",
             "; ".join(unknown))
    else:
        emit("policy.exemptions.unknown", "G-C", True, "pass", 0,
             "policy.exemption_unknown",
             "trackedBy references resolve to existing work items",
             f"{len(exemptions)} exemption(s) checked")
    if stale:
        emit("policy.exemptions.stale", "G-C", True, "fail", 1,
             "policy.exemption_stale", "trackedBy items are not complete",
             "; ".join(stale))
    else:
        emit("policy.exemptions.stale", "G-C", True, "pass", 0,
             "policy.exemption_stale", "trackedBy items are not complete", "")


def required_stages_problems(info, state):
    """First violation of §8's additive-only rules, or (None, None)."""
    effective = info.get("requiredStages") or []
    derived = info.get("derivedRequiredStages")
    source = info.get("source")
    justification = state.get("requiredStagesJustification")
    if source == "explicit":
        if (any(stage not in CANONICAL for stage in effective)
                or len(effective) != len(set(effective))):
            return ("policy.invalid_stages",
                    "requiredStages must contain unique vocabulary stages")
        order = [CANONICAL.index(stage) for stage in effective]
        if order != sorted(order):
            return ("policy.invalid_stages",
                    "requiredStages must be an ordered subsequence of the stage vocabulary")
        if derived:
            if any(stage not in effective for stage in derived):
                missing = ", ".join(stage for stage in derived if stage not in effective)
                return ("policy.stage_reduction_forbidden",
                        f"explicit requiredStages omits derived stage(s): {missing}")
            relative = [stage for stage in effective if stage in derived]
            if relative != derived:
                return ("policy.stage_reduction_forbidden",
                        "explicit requiredStages reorders derived stages")
            if effective == derived:
                if justification is not None:
                    return ("policy.justification_required",
                            "requiredStagesJustification must be absent when the "
                            "explicit list equals the derived value")
            elif not isinstance(justification, str) or not justification.strip():
                return ("policy.justification_required",
                        "requiredStagesJustification (non-empty) required when the "
                        "explicit list adds stages")
        # class unknown with an explicit list: derivation impossible, and the
        # classification row already failed — nothing further to check here.
    elif source == "derived":
        if justification is not None:
            return ("policy.justification_required",
                    "requiredStagesJustification must be absent when the list is derived")
    return (None, None)

ARTIFACT_KEYS = ("stage", "task", "inputFingerprint", "outputFingerprint",
                 "taskFingerprint", "gitHead", "generatedAt")
HEX64 = re.compile(r"\A[0-9a-f]{64}\Z")


def parse_artifact(path, stage):
    """(header, body) for a valid stage artifact (§5); ValueError otherwise."""
    with open(path, encoding="utf-8") as handle:
        text = handle.read()
    match = re.match(r"\A---\n(.*?)\n---\n", text, re.S)
    if not match:
        raise ValueError("missing or unterminated front matter block")
    header = {}
    for line in match.group(1).split("\n"):
        key, sep, value = line.partition(":")
        if not sep or key in header:
            raise ValueError("front matter line is not a unique key: value: %r" % line)
        header[key.strip()] = value.strip()
    problems = []
    missing = [key for key in ARTIFACT_KEYS if key not in header]
    unknown = sorted(key for key in header if key not in ARTIFACT_KEYS)
    if missing:
        problems.append("missing keys: " + ", ".join(missing))
    if unknown:
        problems.append("unknown keys: " + ", ".join(unknown))
    if not missing:
        if header["stage"] != stage:
            problems.append("stage %r does not match artifact %r"
                            % (header["stage"], stage))
        if header["task"] != TASK_ID:
            problems.append("task %r does not match %r" % (header["task"], TASK_ID))
    for key in ("inputFingerprint", "outputFingerprint", "taskFingerprint"):
        if key in header and not HEX64.match(header[key]):
            problems.append("%s is not a 64-hex digest" % key)
    for key in ("gitHead", "generatedAt"):
        if key in header and not header[key]:
            problems.append("%s must be non-empty" % key)
    if problems:
        raise ValueError("; ".join(problems))
    return header, text[match.end():]


def trace_tokens(body):
    """Sorted catalog ids under the artifact's "## Traces" section (§9.3)."""
    collecting, lines = False, []
    for line in body.split("\n"):
        if line.startswith("## "):
            collecting = line.strip() == "## Traces"
            continue
        if collecting:
            lines.append(line)
    return sorted(set(re.findall(r"\bC-[A-Z0-9]+-\d+\b", "\n".join(lines))))

def command_tail(proc):
    """Last non-empty line of stderr, else stdout — one line, TSV-safe."""
    for stream in (proc.stderr, proc.stdout):

    return ""


def verification_rows():
    """§6.2/§8.3: with a task id, G-C executes the item's verificationCommands
    — required checks, status-independent, run from the repository root."""

# --- gauntlet view (design §7, §8.1, §10) ------------------------------------

ARTIFACT_KEYS = {"stage", "task", "inputFingerprint", "outputFingerprint",
                 "taskFingerprint", "gitHead", "generatedAt"}
HEX64 = re.compile(r"\A[0-9a-f]{64}\Z")
TASK_ID_RE = re.compile(r"\AFJ-[A-Za-z0-9-]+\Z")


def parse_artifact(path):
    """Stage-artifact front matter (design §5) under the same rules the engine
    applies: `key: value` lines only, exact seven-key set, stage/task/digest
    validation. Returns (header, body); raises ValueError when invalid."""
    with open(path, encoding="utf-8") as handle:
        text = handle.read()
    if not text.startswith("---\n"):
        raise ValueError("missing front matter")
    end = text.find("\n---\n", 4)
    if end < 0:
        raise ValueError("unterminated front matter")
    header = {}
    for line in text[4:end].splitlines():
        if line != line.lstrip() or ": " not in line:
            raise ValueError("invalid front matter line: %r" % line)
        key, value = line.split(": ", 1)
        if key in header:
            raise ValueError("duplicate front matter key: %s" % key)
        header[key] = value
    if set(header) != ARTIFACT_KEYS:
        raise ValueError("front matter keys %s != %s"
                         % (sorted(header), sorted(ARTIFACT_KEYS)))
    if header["stage"] not in STAGE_NAMES:
        raise ValueError("unknown stage %r" % header["stage"])
    if not TASK_ID_RE.match(header["task"]):
        raise ValueError("invalid task %r" % header["task"])
    for key in ("inputFingerprint", "outputFingerprint", "taskFingerprint"):
        if not HEX64.match(header[key]):
            raise ValueError("%s is not a 64-hex digest" % key)
    return header, text[end + 5:]


def due_stages(status, current_stage, required):
    """§8.1 due set for display — the same rules `scripts/candidate-fingerprint`
    scheduling() applies (interpretation note 8): display never invents its own."""
    if status in ("planned", "ready", "blocked"):
        return []
    if status in ("review", "complete"):
        return list(required)
    if current_stage in required:
        stop = required.index(current_stage)
        return required[:stop] if status == "implementing" else required[:stop + 1]
    return list(required)  # no stage, or a stage outside requiredStages: fail-closed


def covered_stage(status, current_stage, required):
    """Terminal-freshness coverage (§7): verifying → the current stage when it
    is required; review/complete → the last required stage; nothing otherwise."""
    if status == "verifying":
        return current_stage if current_stage in required else None
    if status in ("review", "complete"):
        return required[-1] if required else None
    return None


def artifact_state(stage, status, current_stage, required, tfp):
    """§7/§8.1 freshness for one stage, recomputed from fingerprints:
    not required | pending | missing | invalid | stale | fresh."""
    if stage not in required:
        return "not required"
    if stage not in due_stages(status, current_stage, required):
        return "pending"
    path = os.path.join(REPO, ".agent", "work", task_id, "%s.md" % stage)
    if not os.path.isfile(path):
        return "missing"
    try:
        header, _body = parse_artifact(path)
    except (ValueError, OSError):
        return "invalid"
    if header["stage"] != stage or header["task"] != task_id:
        return "invalid"
    if header["taskFingerprint"] != tfp:
        return "stale"
    position = required.index(stage)
    if position > 0:
        previous = os.path.join(REPO, ".agent", "work", task_id,
                                "%s.md" % required[position - 1])

                return "stale"
    if covered_stage(status, current_stage, required) == stage and CAND_FP \
            and header["outputFingerprint"] != CAND_FP:
        return "stale"
    return "fresh"

````markdown
## Stage artifacts: `.agent/work/<id>/{specifier,coder,cleaner,hardener,qa}.md`

One artifact per executed stage: concise prose — what was done, what was found,
what remains — below the required front matter block (design §5):

```yaml
---
stage: hardener
task: FJ-017
inputFingerprint: 9f2c…
outputFingerprint: 4ab1…
taskFingerprint: 7c2e…
gitHead: a5a7846
generatedAt: 2026-09-25T11:00:00Z
---
```

- `inputFingerprint` / `outputFingerprint` — the workspace content digest
  (§6.1) before and after the stage; the next required stage must link to your
  output (`B.inputFingerprint == A.outputFingerprint`).
- `taskFingerprint` — the task-semantics digest (§6.2) recorded when the stage
  ran; verification requires it to equal the current value.
- `gitHead` — diagnostic metadata only, never evidence identity.

Verification is fingerprint-bound: a broken chain link, a recorded fingerprint
that no longer matches, or a stale terminal artifact fails
`stage.evidence_stale`; an unparseable header fails `stage.evidence_invalid`;
a due stage with no artifact fails `stage.artifact_missing`.

**Artifacts are evidence, never verdicts.** No `status`/verdict field exists in
an artifact — only `./scripts/verify-candidate` emits
`pass | fail | skipped | not_applicable`, and only in reports under
`.agent/reports/<task-id>/`. Commit artifacts as needed, like any other work
state.
````

````markdown
## Gate policy: `.agent/gate-policy.json`

Reviewable bootstrap waivers for required checks whose tooling does not exist
yet (design §9.2). v1 commits exactly four exemptions:

| gate | blocks | scope | code | trackedBy |
|------|--------|-------|------|-----------|
| `G-L` | `stage.tooling_absent` | product, metadata | `stage.tooling_bootstrap_exempt` | FJ-044 |
| `G-H` | `stage.tooling_absent` | product | `stage.tooling_bootstrap_exempt` | FJ-045 |
| `G-Q` | `stage.tooling_absent` | product, metadata | `stage.tooling_bootstrap_exempt` | FJ-046 |
| `G-C` | `toolchain.pyyaml_missing` | product, metadata | `toolchain.pyyaml_exempt` | FJ-047 |

Each entry is `{gate, blocks, scope, code, reason, trackedBy}`. A waiver
matches a blocking check only when **all** of these hold: `gate` equals the
check's gate; `blocks` contains the code the check would otherwise report; the
item's path class is in `scope`.

`trackedBy` must name an existing work item whose `status` is not `complete`:
an unknown id fails `policy.exemption_unknown`, a completed tracker fails
`policy.exemption_stale` — exemptions clean up after themselves instead of
lingering.

Exemptions apply only to `skipped` rows: they never waive a `fail`, and they
never manufacture a `pass` — a matched check stays visible as `skipped` with
the exemption's `code`. Exemptions are policy, not worker choice: they live in
this file, are reviewed like any other change, and are never toggled per task.
````

```bash
CAND_FP="$(./scripts/candidate-fingerprint candidate)"
python3 - "$CAND_FP" <<'PY'
import json, pathlib, subprocess, sys

cand_fp = sys.argv[1]
head = subprocess.run(["git", "rev-parse", "--short", "HEAD"],
                      capture_output=True, text=True, check=True).stdout.strip()
GENERATED_AT = "2026-09-25T00:00:00Z"   # fixed: no wall-clock, deterministic

for task_id in ("FJ-PRD-001", "FJ-043"):
    work = pathlib.Path(".agent") / "work" / task_id
    info = json.loads(subprocess.run(
        ["./scripts/candidate-fingerprint", "task", str(work / "state.json")],
        capture_output=True, text=True, check=True).stdout)
    tfp = info["taskFingerprint"]
    for stage in info["requiredStages"]:
        header = (
            "---\n"
            "stage: %s\n"
            "task: %s\n"
            "inputFingerprint: %s\n"
            "outputFingerprint: %s\n"
            "taskFingerprint: %s\n"
            "gitHead: %s\n"
            "generatedAt: %s\n"
            "---\n" % (stage, task_id, cand_fp, cand_fp, tfp, head, GENERATED_AT))
        body = ("# %s — retroactive evidence\n\n"
                "Recorded at the end of the gauntlet rollout (plan task 11). "
                "The stages for this item were executed as the plan's documentation "
                "and tooling work; this artifact binds that evidence to the final "
                "workspace content and task semantics. No verdict is declared here — "
                "verification results live only in .agent/reports/.\n"
                % stage)
        (work / ("%s.md" % stage)).write_text(header + "\n" + body, encoding="utf-8")
    print("%s tfp=%s" % (task_id, tfp))
PY
```

`.agent/work/{FJ-PRD-001,FJ-043}/{specifier,coder,cleaner,qa}.md`.

Invariants this construction guarantees:

- `generatedAt` is a fixed constant — no wall-clock value lands in a committed
  artifact; `gitHead` is diagnostic metadata only (§5);
- each body has no `## Traces` section, so G-S's trace check passes vacuously
  (it fails only on unknown IDs *under* that heading);
- no `status`/verdict field appears anywhere in an artifact — verdicts exist
